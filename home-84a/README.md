# 우리 집 84A — 3D 집 모형

우리 집(84A 확장형 평면)을 three.js로 만든 3D 모형이며, 도화서 저장소에 보관합니다.

- **보는 곳:** Claude 아티팩트로 게시해 두고 링크로 봅니다. 이 폴더의 `index.html`이 원본이고, 고친 뒤에는 같은 아티팩트 주소로 다시 게시합니다.
- **실행:** 브라우저로 `index.html`을 열면 됩니다. three.js r147과 웹 폰트를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 좌표 규칙

- 모든 형상은 분양 평면도 이미지의 **픽셀 좌표**로 적고, `1px = 4.2cm`(`S = 0.042`)로 미터로 바꿉니다.
- 평면도 x → 월드 +X(동), 평면도 y → 월드 +Z(남, 거실 창 방향). 천장 높이는 2.3m입니다.
- 실제 집은 분양 평면도의 **좌우 반전**입니다. 그래서 `house.scale.x = -1`이 기본이고, 화면의 '좌우 반전' 버튼으로 끄고 켭니다. 사진을 보고 위치를 정할 때는 반전된 상태를 기준으로 봅니다.
- 욕실 기구(욕조·세면대·변기)는 각자의 로컬 좌표에서 만듭니다. 뒷면이 벽(z = 0)에 붙고 +z 방향을 봅니다. 그다음 `place(obj, px, py, rotY)`로 평면도 위에 놓습니다.

## 주요 조작

집 둘러보기 · 시각(태양 위치: 부천, 오늘 날짜) · 조명 자동/켜기/끄기 · 벽 높이 · 가구 예시 · 좌우 반전 · 자동 회전 · 문 클릭으로 열고 닫기
