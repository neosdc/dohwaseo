# 한울호 디오라마 — 우주선 단면 3D 디오라마

가상의 우주선 한울호(ISV-07) 주갑판을 위에서 비스듬히 내려다본 three.js 디오라마이며, 도화서 저장소에 보관합니다.

- **보는 곳:** Claude 아티팩트로 게시해 두고 링크로 봅니다. 이 폴더의 `index.html`이 원본이고, 고친 뒤에는 같은 아티팩트 주소로 다시 게시합니다.
- **실행:** 브라우저로 `index.html`을 열면 됩니다. three.js r147(`OrbitControls` 포함)과 웹 폰트(Chakra Petch, IBM Plex Sans KR)를 CDN에서 불러오므로 인터넷 연결이 필요합니다. WebGL을 쓸 수 없으면 안내 문구만 나옵니다.

## 장면

- **선체:** 화면에는 전장 190 m로 적혀 있습니다.
  - 선수(+x): 착륙 패드와 셔틀, 센서 돔, 회전하는 접시 안테나, 주포탑 2기
  - 선미(−x): 방열 핀과 주 추진기 3기
  - 양현: 태양 전지 날개를 단 긴 추진 나셀
  - 갑판 가장자리: 근접 방어 포탑 6기
  - 선체 옆면: 4층으로 난 현창
- **구획 26개** (코드는 바닥에 찍힌 표시와 같습니다):

  | 구역 | 구획 |
  |---|---|
  | 선수 5개 | 조종실 `A-01` · 전투정보실 `T-19` · 작전 회의실 `B-18` · 무기고 `X-17` · 격납고 `V-20` |
  | 중앙 14개 | 수경재배실 `H-03` · 휴게실 `L-04` · 선실 A `Q-05` · 정수실 `W-06` · 창고 A `C-07` · 의무실 `M-08` · 보전반 `N-09` · 로봇 수리실 `R-10` · 연구실 `S-11` · 선실 B `Q-12` · 창고 B `C-13` · 식당 `G-14` · 체력단련실 `F-15` · 선실 C `Q-16` |
  | 선미 7개 | 전산실 `D-21` · 공작실 `P-22` · 연료 저장고 `U-23` · 보안실 `K-24` · 어뢰실 `Y-25` · 생명유지실 `O-26` · 엔진실 `E-02` |

- **바닥 표시:** 구획마다 바닥에 코드·영문·한글 이름이 찍혀 있습니다(예: `A-01 BRIDGE 조종실`).
- **좌표:** 1 단위 ≈ 1 m, 바닥면이 y = 0입니다. +x가 선수, −x가 선미입니다.
  - 가로 복도는 셋입니다: A(z = 0), B(z = −11), C(z = 11). 복도 A는 선미 구획(x −51…−17)과 선수 구획(x 17…51) 안까지 이어집니다.
  - 세로 연결 복도는 둘입니다: W(x = −15.5), E(x = 15.5).
  - 중앙 구획은 x −17…17에 있고, 바깥 구획은 z ±12.5…20.5에 있습니다. 조종실(x 51…59)과 엔진실(x −61…−51)은 복도 A 끝에 있습니다.
- **배치 고정:** 가구와 소품 배치는 고정 시드(`20261110`)의 난수로 정하므로 열 때마다 같습니다. 복도 로봇이 갈림길에서 고르는 방향만 매번 달라집니다.

## 움직임

- **승무원과 로봇:** 사람 20명과 휴머노이드 로봇 6대가 구획의 작업 자리 112곳 사이를 오갑니다.
  - 자리마다 자세가 정해져 있습니다: 서서 일하기, 앉기, 눕기(잠든 사람 위로 `Z`가 떠오름), 러닝머신 달리기, 벤치 프레스.
  - 로봇은 서서 일하는 자리만 쓰고, 로봇 수리실의 충전 포드 3곳은 로봇만 씁니다.
  - 창고에서 다른 구획으로 갈 때는 상자를 들고 갑니다.
- **경로:** 복도 중심선 위의 지점 26곳(갈림길과 문 앞)을 이은 그래프에서 다익스트라로 최단 경로를 찾습니다. 복도에서는 우측 통행합니다.
- **문:** 문은 28개이며, 누가 1.7 m 안에 오면 미닫이가 열리고 표시등이 초록에서 주황으로 바뀝니다.
- **함재기:** 격납고에서 발진합니다.
  - 격납고의 주기 구역 4곳에 3기가 세워져 있고, 한 구역은 1번기가 오가는 자리입니다.
  - 초계 편대 3기가 선체 둘레를 계속 돕니다.
  - 1번기는 약 80초 주기로 정비 → 발진 → 초계 비행 → 귀환을 반복합니다. 화면 오른쪽 아래 상태 창에 그 단계가 표시됩니다.
- **로봇과 드론:**
  - 휴머노이드 6대(위 승무원과 같이 오감)
  - 복도를 돌아다니는 청소 로봇 6대와 순찰 드론 6대
  - 지게차 로봇 1대, 관수·수리·화물 드론 각 1대
  - 선체 바깥을 도는 화물 드론 3대
- **구획 안의 기계:** 공작실의 적층 제조기와 컨베이어, 어뢰실의 장전 레일, 반응로 고리, 정수 탱크 기포, 증기, 용접 불꽃, 로봇 팔이 움직입니다. 격납고 발진구에는 역장이 쳐져 있습니다.
- **그 밖의 움직임:**
  - 10fps로 바뀌는 모니터 화면(레이더, 막대그래프, 파형, 글자, 행성)
  - 포탑이 좌우로 훑고, 엔진 불꽃이 일렁입니다.
  - 고양이 꼬리, 샌드백
  - 선체가 천천히 오르내리고, 배경 별은 선미 쪽으로 흐릅니다.
- **동작 줄이기:** 운영체제의 '동작 줄이기' 설정이 켜져 있으면 선체 흔들림과 별 흐름을 멈춥니다.
- **성능:** 그림자 맵은 두 프레임에 한 번만 갱신합니다. 점광원이 많아서 대부분 Lambert 재질을 씁니다. 프레임이 26fps 아래로 3초 넘게 이어지면 해상도를 1배로 낮추고, 그래도 느리면 그림자를 끕니다. 현재 품질은 상태 창에 나옵니다.

## 화면 구성

- **왼쪽 위:** 함선 이름과 시뮬레이션 시계(`T+ 시:분:초`), 현재 배속, 전장·구획·승무원 수
- **오른쪽 위:** 배속(일시정지·1×·2×·4×·8×), 자동 회전, 전체 보기, 구획 목록 켜고 끄기
- **왼쪽:** 구획 목록(`DECK DIRECTORY`). 구역별로 나뉘고, 구획마다 지금 일하는 사람·로봇 수가 보입니다. 누르면 그 구획을 테두리로 표시하고 카메라가 이동합니다. 좁은 화면에서는 목록이 처음에 접혀 있습니다.
- **왼쪽 아래:** 선택한 구획의 정보와 미니맵. 미니맵의 점은 승무원(흰색)·로봇(파랑)·복도 로봇(초록)·드론(주황)·1번기(노랑)이고, 십자는 화면 중심입니다. 1번기 점은 초계 비행 중에는 격납고에서 멀리 있는 동안 나오지 않습니다. 미니맵을 누르면 그 위치로 이동합니다.
- **오른쪽 아래:** 상태 창. 승무원(근무·이동·휴식), 로봇, 함재기, 성능을 보여 줍니다.

## 조작

- **마우스·터치:** 드래그로 회전 · 휠/핀치로 확대 · 우클릭 또는 두 손가락 드래그로 이동 · 3D 화면을 더블클릭하면 그 자리의 구획을 선택
- **키보드:** `Space` 일시정지 · `1`~`4` 배속(1×·2×·4×·8×) · `O` 자동 회전 · `R` 전체 보기 · `Esc` 선택 해제

처음 화면은 선체 전체가 들어오는 거리에서 정등각 방향으로 봅니다. 시뮬레이션 시계와 배속은 사람·로봇·기계·함재기 움직임과 별 흐름에 적용됩니다. 일시정지하면 이들이 모두 멈추고, 카메라 조작과 구획 이동은 계속 됩니다.

개발자 도구에서 `window.__diorama`로 승무원, 작업 자리, 문, 복도 로봇, 경로 그래프, 구획 정보(`META`)를 볼 수 있습니다. `setSpeed(n)`, `selectRoom(id)`, `frameAll()`도 쓸 수 있습니다.
